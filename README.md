# Análise de Vendas com Power BI

Projeto de Business Intelligence para análise de dados de vendas utilizando Power BI, Power Query e DAX.

---

## Sobre o projeto

Este projeto tem como objetivo desenvolver uma solução de Business Intelligence capaz de transformar dados brutos em informações estratégicas para apoiar a tomada de decisão.

Ao longo do desenvolvimento serão aplicados conceitos de ETL, modelagem de dados, criação de medidas em DAX e construção de dashboards interativos, seguindo boas práticas de análise e visualização de dados.

---

## Objetivos

- Transformar dados em informações úteis.
- Construir um modelo de dados eficiente.
- Desenvolver indicadores de desempenho (KPIs).
- Criar dashboards interativos e intuitivos.
- Aplicar boas práticas de Business Intelligence.

---

## Tecnologias Utilizadas

- Power BI Desktop
- Power Query
- DAX
- Microsoft Excel

---

## Conteúdos Desenvolvidos

### ETL

- Importação de dados
- Tratamento de dados
- Limpeza de informações
- Padronização de dados

### Modelagem de Dados

- Relacionamentos entre tabelas
- Cardinalidade
- Organização do modelo
- Criação da Tabela Calendário
- Relacionamento da Tabela Calendário com o modelo
